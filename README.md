# PackFlow

PackFlow 是一个面向游戏发行、渠道运营、美术协作团队的素材包整理工具。

它可以把一堆素材压缩包自动整理成干净的交付包：

- 批量解压 zip / rar / 7z
- 自动汇聚多层目录里的真实素材文件
- 按图片真实尺寸分类，例如 1024x1024、1080x1920
- 极简命名，例如 001.jpg、002.jpg
- 生成素材清单 CSV
- 输出 final_materials.zip 交付包
